# KineTrexa – Corporate Website

A modern, responsive multi-page corporate website designed with a clean UI, smooth animations, and an enhanced user experience.

## 🌐 Project Overview

KineTrexa is a modern corporate website that provides information about the company, its services, portfolio, career opportunities, and contact details.

## ✨ Key Features

* 📱 Fully Responsive Design
* 🎨 Modern and Clean UI
* 🌓 Dark / Light Theme
* ✨ Smooth Animations & Transitions
* 🔍 SEO-Friendly Layout
* 📩 Contact Form
* 🏠 Home Page
* 👥 About Page
* 🛠️ Services Page
* 💼 Portfolio Page
* 💻 Careers Page
* 📞 Contact Page

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* CSS Animations & Transitions

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No additional installation is required.
